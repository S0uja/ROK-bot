# ROK-bot

Automation framework for Rise of Kingdoms.

## Goals
- Android emulator / ADB control
- Screenshot capture
- Computer vision and OCR
- State-based automation
- Modular game tasks
- Multi-account support
- Web dashboard

## Project status
Early development.

## Planned stack
- Python 3.11+
- ADB
- OpenCV
- OCR
- FastAPI + web UI (later)
